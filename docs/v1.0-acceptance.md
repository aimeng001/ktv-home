## 本次整改（R01–R05 及后续一致性收口）

本轮按最小范围修复了已核实的问题：统一原唱切换能力判断、补齐新曲库目录监听、抑制过期播放错误广播、外部曲库管理操作默认隐藏/拒绝，以及将媒体与歌词 sidecar 快照分离。R05 使用 V20 加 V21 追加迁移；V21 将已存在的 `SMALLINT` 无损扩宽为实体对应的 `INTEGER`。歌词仅发生变化时，测试实测 `FFprobe=0`、完整 Hash=0，媒体文件字节保持不变；带有 `[ti]`/`[ar]` 身份标签的歌词变化则保守触发一次媒体探测。未修改源媒体文件。

本轮补充了文件级媒体语义、AudioLayout 来源、Song 播放投影、文件恢复状态和设置契约的最小改动：外部单音轨默认可解析为 `DUAL_CHANNEL`，多音轨安全回落为 `DUAL_TRACK`，人工设置优先于自动默认；管理后台和播放页人工交换后重新计算/保留 Song 投影；新增 V25 仅追加字段并为旧记录保留安全的 `LEGACY` 默认。以上为上一阶段功能记录；本轮整改回归数字以“本机验证”表为准。

两项 skip 均未伪装为通过：`IncrementalLibraryScanTest` 的文件身份替换用例仅在文件系统提供变化身份时执行，`LargeLibraryMemoryTest` 需显式设置 `runLargeLibraryTest=true` 才运行。
